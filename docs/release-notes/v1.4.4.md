## New in 1.4.4

- Improve Automix scoring and add feedback controls for recommendations. Keep Quran recitations separate from music in the automatic queue.
- Restore downloaded songs from MP3 files that survive clearing Android app data. Velune rebuilds missing download entries and can recover the song ID from the original filename when the embedded tag is unreadable.
- Migrate the Linux desktop interface to Qt Quick (QML) and update the installation guide.
- Improve desktop Connect playback handover, resume handling, and backup and local storage behavior.
