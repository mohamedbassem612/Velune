## New in 1.4.3

- Add light horizontal drag motion and a smooth return for the new and classic mini players. Short drags return without skipping a song.
- Make the mini player design, swipe toggle, and swipe sensitivity available in Appearance for the current player.
- Prevent disabled swipe gestures from opening the full player accidentally.
- Open Sleep Timer in the same bottom sheet as Connect, with a moon slider thumb, a soft halo while dragging, and animated minute changes.
- Balance the Like and Repeat icons in media notifications with the playback controls, including their active states.
- Give these updates a new version number so installations on 1.4.2 can detect them as an update.
